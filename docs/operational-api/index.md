# Operational API

[OpenAPI Specification Documentation](../openapi/operational/index.html){target=_blank .md-button }

The ADT Operational API consists of these functional areas:

1. [Introduction](intro.md) — data model, authentication and common headers.
2. [Journey API](journey.md) — look up lines, stop points and journeys.
3. [Assignment API](assignment.md) — sign vehicles on and off journeys.
4. [Deviation API](deviation.md) — report service deviations.
5. [Mitigation API](mitigation.md) — mitigate service deviations (internal use).
