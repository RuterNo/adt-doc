# Speaker requirements

## Introduction

The following list of requirements is intended for the PTO to adhere to when new vehicles are produced. These are general
requirements and must be followed in addition to those outlined in the specific _Materialbeskrivelse_.

In the event of a conflict between the requirements in the _Materialbeskrivelse_ and the general requirements listed below,
the _Materialbeskrivelse_ requirements take precedence.


## General requirements

### Background

The requirements outlined in this document are designed to ensure compliance with Section 4 of the 
[Forskrift om universell utforming av motorvogn i løyvepliktig transport mv](https://lovdata.no/forskrift/2009-12-03-1438/§4), which 
governs the universal design of ICT solutions. This regulation emphasizes the importance of providing accessible, reliable, 
and timely information to all users, regardless of physical or cognitive abilities, to promote inclusivity and equality.

### Speaker Groups


The vehicle's audio system must support three distinct speaker groups, each serving a specific purpose. These groups and 
their requirements are outlined below:

| **Speaker Group** | **Purpose**                                      |
|-------------------|--------------------------------------------------|
| Passenger         | Announcements for passengers inside the vehicle. | 
| Driver            | Communication for the driver’s area.             | 
| External          | Announcements outside the vehicle.               | 

Each speaker group must have independent volume control to ensure sound levels can be tailored to specific needs without 
affecting the other groups. This setup enhances audio clarity and ensures optimal performance in different environments.


### Volume and Sound Level Requirements

The configured volume settings must be tested to ensure they are suitable for the vehicle. The table below specifies the 
acceptable range for dB and STIPA for each speaker group.

- **[STIPA](https://en.wikipedia.org/wiki/Speech_transmission_index)** (Speech Transmission Index for Public Address Systems) 
is required for **Normal** and **High** sound levels but should also be measured for **Low**.

---

### Sound Levels per Speaker Group

| **Speaker Group** | **Level** | **dB Range** | **STIPA Requirement** |
|-------------------|-----------|--------------|-----------------------|
|                   |           |              |                       |
| **Passenger**     | Low       | 60-62 dB     | N/A                   |
| **Passenger**     | Normal    | 68-70 dB     | 0.5 or higher         |
| **Passenger**     | High      | 72-74 dB     | 0.5 or higher         |
|                   |           |              |                       |
| **External**      | Low       | 59-61 dB     | N/A                   |
| **External**      | Normal    | 64-66 dB     | 0.5 or higher         |
| **External**      | High      | 69-71 dB     | 0.5 or higher         |
|                   |           |              |                       |
| **Driver**        | Low       | 59-61 dB     | N/A                   |
| **Driver**        | Normal    | 64-66 dB     | 0.5 or higher         |
| **Driver**        | High      | 69-71 dB     | 0.5 or higher         |
